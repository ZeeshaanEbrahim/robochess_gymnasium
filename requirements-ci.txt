# CI dependency set.

# requirements.txt is the FROZEN EXPERIMENT SET and is never installed in CI:
# it pins a CUDA torch build plus ~15 nvidia-* packages, roughly 4.5 GB of
# wheels, on runners that have no GPU to use them. This file installs the same
# torch *version* built for CPU instead, so CI exercises the same code paths
# without the CUDA payload.
#
# Versions here mirror requirements.txt deliberately. If you bump a pin there
# and it is listed below, bump it here too -- there is no automatic link.
