## 5. Deviations and disclosures

a. First launch killed at 02:09:43 on 2026-10-06 by a WSL distro shutdown (trigger unknown). All four runs restarted from step 0 at 12:39:40 on SHA ac84418 with identical configs. The partial first-launch output is in `runs/_died_20261006__probe_cart_rs31{C_seed0,C_seed1,D_seed0}` plus `_train.log` files and is not evaluated.
b. Env seed streams overlap: SB3 seeds env i with seed+i (`VecEnv.seed`). C seed0 uses env seed 0, C seed1 env seed 1, D seed0 env seeds 0 to 3, D seed1 env seeds 1 to 4.
c. Run end steps: C 3,000,320 (1465 rollouts of 2048), D 3,006,464 (367 rollouts of 8192). Gated evaluation uses the final model. Training diagnostics use the 3,000,000 checkpoint.
d. D writes four Monitor files (`monitor_0` to `monitor_3`); C writes one.
e. D arm is a bundle (n_envs 4 plus linear LR decay to 0), so a D versus C difference cannot be attributed to either factor alone.
f. Reporting choices where the preregistration is silent: 48 deterministic episodes, chunking by cumulative episode length, 3,000,000 checkpoint for std.
g. Check start time for the runs/ modification check: 2026-10-06 17:24:49 SAST.
h. `rms_wrapper.py` runs `scripts/eval_probe.py` unmodified through `runpy` and records `ret_rms` as well as `obs_rms` (mean, var, count) before and after each evaluation. It was added because `eval_probe.py` records only the `obs_rms` before/after flag and that file may not be edited. The equivalence with plain `eval_probe.py` is in 4.7.
i. Rule 3 outcome is a mechanical decision rule. D bundles n_envs 4 and linear LR decay, so the result cannot be attributed to either factor. Two seeds per arm. C seed 1 scored 530/1200 against the fixed 600 threshold.
j. Funnel columns: `grasp_ever` means lift over 10 mm (it undercounts). `lifted_30mm` and `carried_within_3cm` are unreliable per RS30 (they read 0 even for a 99.3% policy) and are not used; they remain in the result JSONs only.
k. Zero-shot (a): 12 pairs on files b and g, never trained, same move type as training. One seed per model.
l. Zero-shot (b) headline = the 19 untrained pairs (n = 285 per model); `e4:e5` is a training pair.
m. Deterministic effective-n: in all four models every pair has 0 or 2 placed episodes and the two episodes of each pair have identical per-step trajectory records (24/24 pairs, computed in `section3_output.txt`). The 48-episode interval assumes independent episodes and is not valid when the two episodes are identical; the effective-n = 24 row (pairs with 2 placed / 24) is reported beside it.
n. Training placement per 100k for D is pooled over the four Monitor files with 100k training steps = 25k file steps each. Training placement is the Monitor `terminated_reason == success` (the Monitor has no separate placement column).
o. C seed 0 gripper std (exp(log_std)) rose from 0.9515 at the 100k checkpoint to 66.0003 at the 3,000,000 checkpoint (65.8444 in the final model); it is above 1.0 from the 500k checkpoint on. The series is not monotone: it decreases at 100k to 200k and 300k to 400k, and the final model is below the 3,000,000 checkpoint (table in 4.4). Reported without a causal claim.
p. No positive control was run in RS31. The RS30 control (D29 squash seed 3, e4:e5, 298/300) used plain `scripts/eval_probe.py`, not `rms_wrapper.py`; the wrapper was compared directly instead (4.7).
